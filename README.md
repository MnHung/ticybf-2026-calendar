# 2026 臺灣國際兒少嘉年華 行事曆

民間自行整理，非文化部或主辦單位官方頁面。官網 https://ticybf.moc.gov.tw 沒有整合行事曆，這裡把 9/23–9/27 所有活動（書展沙龍、Young Boom! 劇場、Tiffi 影展、特別企劃、暖身活動）合併成一份時間表。

- 網頁版（全部活動）：https://mnhung.github.io/ticybf-2026-calendar/
- 依孩子年齡篩選：https://mnhung.github.io/ticybf-2026-calendar/kids/ （預設 5–6 歲，可選年齡區間；網址可帶 `?age=5-6`、`&unk=1`）
- 行事曆檔（可匯入 Google／Apple 日曆）：`ticybf_2026.ics`（全部活動，不含年齡篩選）

資料抓取日 2026-09-20，場次以官網為準。

## 年齡標籤怎麼來的

官網沒有統一的「適合年齡」欄位，`/kids/` 的每場標籤分三種：

| 標籤 | 來源 | 場次 |
|---|---|---|
| 官網 | 官網明載：影展場次表的 Age、Young Boom! 劇場的「年齡建議」、特別企劃的「參加對象」。影展「青少年」以 12–18 歲計；3 場影展節目頁所列影片皆標 4+，以 4 歲以上計 | 72 |
| 推估 | 我讀活動說明後的判斷（規則見下），頁面每列附「推估依據」；可能有誤，僅供參考 | 95（另有暖身活動 17） |
| 年齡未標示 | 看不出適合誰，預設隱藏，可勾選顯示 | 26（另有暖身活動 2） |

推估規則：講者簡介裡的「幼兒／國小」不算證據；場地名只是弱線索；內容明顯給家長、教師、創作者的標為成人場；分不出就標「年齡未標示」。範圍比對採「有交集就列出」（選 5–6 歲時，「6 歲以上」的活動也會出現）；成人場只在「從」選到「18 歲以上」時列出。
